# START HERE

This repository is a Unity project for importing Lineage II Interlude client assets into Unity.

## Main entry point

1. Open this repository as a Unity project.
2. In Unity, open `L2 > Startup`.
3. Use the Startup window as the main control panel for imports:
   - map and terrain import
   - creature prefab import
   - player character archetype import
   - skill visual import

The Unity editor window implementation is here:

`Assets/Editor/L2StartupWindow.cs`

## Source client data

The importer expects a Lineage II Interlude client path in the relevant import panels.

Existing project notes and links are in `README.md`.
